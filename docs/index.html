Installfrom zero

  1. Get the plugin. Download the archive above and unpack it, or clone the repository.
  2. Add it to your profile. Use the CLI that ships with DSH: dsh plugin --profile desktop add <directory>. Or skip this step entirely and mount it by absolute path — the plugin has no runtime dependencies.
  3. Write the patch. Paste the generated YAML into ~/.dsh/profiles/desktop/cordis.patch.yml. Do not edit cordis.yml: it is rewritten to [] on every launch.
  4. Fetch the artwork. In the plugin directory, run npm run fetch-art. The official art is not in the repository; this is the step that downloads it to your machine.
  5. Restart DSH Desktop. The desktop composes its patch layers once per launch, so reloading the page is not enough.
