Mascot Console看板娘配置台

界面主题 / Theme

在浏览器里决定这个插件开不开、用可露希尔还是千石由乃、开哪几套形象、 要不要骨骼动效与余额查询 —— 然后把生成好的配置贴进 DSH 的 profile。 这个页面不会碰你的机器：它只是把选择写成一段 YAML。

Plugin插件开关

两位角色各有一套界面风格，不只是换颜色：形状、进度条、环境动效、数字字体都不同。

03

Looks可选形象

勾掉的形象会被写进配置的 allowlist：插件连列都不会列出来。 素材本身不在仓库里，靠 npm run fetch-art 下载到本机。

04

Motion动效

骨骼动效 按轮廓自动绑三根骨头、用网格蒙皮做呼吸与重心摆动。不支持 WebGL2 的机器会自动退回静图。
多帧形象 两帧以上的形象（例如会转身的 Q 版）参与轮换。关掉只保留每种形象的第一帧。

Install怎么装

  1. 拿到插件。下载上面的压缩包解压，或者 git clone 仓库。
  2. 装进 profile。用 DSH 自带的 CLI：dsh plugin --profile desktop add <目录>； 或者干脆不装，直接在 patch 里用绝对路径挂载（插件零运行时依赖）。
  3. 写入 patch。把上面生成的 YAML 贴进 ~/.dsh/profiles/desktop/cordis.patch.yml。 注意 cordis.yml 每次启动都会被改写成 []，不要动它。
  4. 下载素材。在插件目录跑 npm run fetch-art —— 官方立绘不在仓库里，这一步才会下载到本机。
  5. 重启 DSH Desktop。桌面端只在启动时组合一次 patch 层，刷新网页没用。
