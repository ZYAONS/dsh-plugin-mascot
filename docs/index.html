立绘是官方游戏素材，所以这里不发布它 —— 这个页面不发布，仓库里也没有。 预览从它唯一存在的地方读取：你自己机器上正在运行的 DSH， 它同时也在 /dsh-mascot/console/ 托管这一页。 从那里打开，下面的框里就会填满你装好的素材，用插件同一套骨架驱动。 在中性主题下，展示骨骼会直接画出骨架本身 —— 由轮廓推出的三根骨头， 以及它们驱动的蒙皮网格。

02

角色谁来出场

每位角色带一整套界面风格 —— 配色、形状、进度条、环境动效、数字字体都不同。 选角色会同时定下立绘和主题，两者不可能对不上。

03

形象允许出现哪几套

没勾上的形象会被写进配置的 allowlist，插件连列都不会列出来。 素材本身不在仓库里 —— 在插件目录跑 npm run fetch-art 才会下载到你机器上。

04

动效怎么动

骨骼动效 按轮廓自动绑三根骨头，用蒙皮网格做呼吸与重心偏移。没有 WebGL2 的机器会退回静态图。
多帧形象 让多于一张的形象（比如会转身的 Q 版）轮流切换。关掉只保留每套的第一帧。

安装从零开始

  1. 拿到插件。下载上面的压缩包解压，或者 git clone 仓库。
  2. 装进 profile。用 DSH 自带的 CLI：dsh plugin --profile desktop add <目录>。也可以跳过这步，直接用绝对路径挂载 —— 本插件零运行时依赖。
  3. 写入 patch。把上面生成的 YAML 贴进 ~/.dsh/profiles/desktop/cordis.patch.yml。不要动 cordis.yml：它每次启动都会被改写成 []。
  4. 下载素材。在插件目录跑 npm run fetch-art。官方立绘不在仓库里，这一步才会把它下载到你的机器上。
  5. 重启 DSH Desktop。桌面端每次启动只组合一次 patch 层，刷新网页没用。
